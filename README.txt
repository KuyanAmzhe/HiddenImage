Программа позволяет скрывать изображение PNG-формата внутри другого.

Скрываемое изображение удовлетворять
следующим условиям:
1) изображение должно быть квадратным;
2) ширина (высота) изображения должна вычесляться по формуле
   f(x) = (x^2/8)^(1/2), где x - ширина (высота) видимого изображения.
